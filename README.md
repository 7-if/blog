# Проект за изработка на сайтове с WordPress за малки и средни бизнеси

Това е проект за изработка на персонализирани сайтове с WordPress, специално насочени към малки бизнеси.

## Цели на проекта
- Персонализирани решения при изработка на уебсайтове за малкия бизнес
- Локална оптимизация за търсачки (Local SEO)
- Лесно управление на съдържание
- Професионален дизайн и мобилна съвместимост
- техническа оптимизация на високо ниво
